    The environment

    A house with four rooms — Living, Garden, Kitchen, Bedroom — each with one useful object. At the start of an episode you're dropped in a random room and given a random quest: You are bored / getting fat / hungry / sleepy. To finish it you must reach the right room and use the right object: watch tv, exercise bike, eat apple, sleep bed.

    The catch: you never see the room's name. Each step you get one of four descriptions of the room, chosen at random — sometimes helpful ("You can watch TV here"), sometimes oblique ("A red juicy fruit."). Formally the hidden state is h = (room, quest) and the observation is s = (room description, quest text).

    Finish the quest+1

    With discount γ = 0.5 the best possible expected reward over random starts is 0.55375: 1 if you start in the right room, 0.49 if it's next door, 0.235 if it's diagonally opposite.

    The agents

    • Tabular Q-learning — one Q-value per (description, quest, action, object): 16 × 4 × 5 × 8 = 2,560 numbers. Learns fast and well, but every new sentence would need its own row.
    • Linear Q with bag-of-words — the text becomes a word-count vector (84 words) and Q(s, c) = θc · φ(s). Generalises across sentences but can't represent the interactions it needs; ends up the weakest.
    • Deep Q-network — the same bag-of-words through a 100-unit ReLU layer with two output heads (actions, objects), trained with SGD on the squared TD error. Matches tabular performance while reading text.

    All three use the same update target r + γ·max Q(s′, ·) and the same ε-greedy schedule. The Train tab runs the exact procedure of agent_tabular_ql.py, agent_linear.py and agent_dqn.py in JavaScript; the Watch tab shows the resulting Q-tables at play time.

    How to play

    You're somewhere in a four-room house, but you only get a description of where you are. A quest tells you what you need. Move with go north / south / east / west and finish the quest with the right command in the right room: watch tv, exercise bike, eat apple, sleep bed.

    Finish the quest+1
    Valid command−0.01
    Invalid command−0.11
    Max steps20

    Your score is the discounted return (γ = 0.5): finishing in one step scores 1, two steps 0.49, three steps 0.235. Learn the house layout and the descriptions and you'll match the optimal agent.
